# CONTEXT — Vehicle Tracking

Repository đã được đưa về trạng thái khởi tạo sạch theo yêu cầu người dùng.

- Frontend: React, TypeScript và Vite skeleton.
- Backend: Spring Boot skeleton với một context-load test.
- Chưa có map, API nghiệp vụ, database, realtime, telemetry hay tích hợp bên thứ ba.
- Không có API key hoặc file `.env` trong baseline.

Mọi chức năng tiếp theo phải được thiết kế lại từ đầu. Không khôi phục code cũ từ
lịch sử Git nếu người dùng chưa yêu cầu rõ ràng.
