# Research

HERE Vector Tile API cung cấp dữ liệu hình học dạng Protobuf/Vector Tile, tối ưu hiển thị 512px. HERE công bố ví dụ dùng MapLibre với style `assets.vector.hereapi.com/styles/berlin/base/mapbox/tilezen`; MapLibre GL Leaflet là adapter để đưa renderer WebGL vào Leaflet.

Nguồn, truy cập 2026-09-15:

- https://docs.here.com/map-rendering/docs/maplibre
- https://docs.here.com/map-rendering/docs/quickstart-vector-tile-api
- https://www.npmjs.com/package/@maplibre/maplibre-gl-leaflet
