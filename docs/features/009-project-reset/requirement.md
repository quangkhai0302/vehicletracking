# Requirement — Project reset

## Yêu cầu

- `REQ-001`: Xóa toàn bộ chức năng, map và tích hợp bên thứ ba hiện có.
- `REQ-002`: Giữ frontend ở mức React/TypeScript/Vite skeleton có thể build.
- `REQ-003`: Giữ backend ở mức Spring Boot skeleton có thể chạy test context.
- `REQ-004`: Xóa file `.env`, API key, build artifact và tài liệu feature cũ.

## Business rule

- `BR-001`: Không xóa thư mục repository hoặc metadata `.git`.
- `BR-002`: Không khôi phục bất kỳ nghiệp vụ cũ nào vào baseline mới.
