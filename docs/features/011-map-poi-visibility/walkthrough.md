# Dùng tùy chọn địa điểm

Lớp bản đồ → Chi tiết bản đồ → Hiển thị địa điểm. Mặc định bật, bỏ chọn yêu cầu nền ẩn tên/icon POI; chọn lại khôi phục URL không có style. State giữ khi chuyển workspace hoặc theme, reset khi tải lại trang.

Source đã nối tùy chọn và build pass. Hành vi ảnh thực tế còn pending theo evidence.md; nếu nhà cung cấp bỏ qua tham số style thì checkbox chưa đáp ứng yêu cầu. Không ẩn tên đường bằng cách xóa toàn bộ nhãn.
